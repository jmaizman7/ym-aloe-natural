# YM Aloe Natural – Landing page

Página estática: `index.html` + carpeta `images/`. No requiere build ni npm.

## Subir a Vercel
1. Descomprime el zip (deben quedar `index.html`, `vercel.json` e `images/` juntos).
2. Entra a https://vercel.com/new, arrastra la carpeta y pulsa Deploy.
   (O con CLI: `npx vercel --prod` dentro de la carpeta.)

## Editar
- Para cambiar una foto, reemplaza el archivo en `images/` conservando el mismo nombre.
- Número de WhatsApp y mensaje: busca `59168756668` al final de `index.html`.
